# Supabase SQL Migrations

This folder contains timestamped SQL migrations for the project schema.

## Conventions

- Each file name starts with a UTC timestamp (for ordering), followed by a short description.
- Apply migrations in ascending file name order.
- Keep migration files immutable after they are applied in shared environments.

## Notes

- Legacy documentation may refer to a top-level `sql/` folder. The authoritative migration location is this directory: `supabase/migrations/`.
