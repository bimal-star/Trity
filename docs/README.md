# Documentation Guide

This directory contains supporting documentation that has been organized away
from the repository root.

## Structure

- `docs/` - active guides that are still part of the current working set
- `docs/reference/` - implementation notes and quick-reference material
- `docs/reports/` - audits and analysis snapshots
- `docs/archive/` - historical summaries and status snapshots
